# BrightPath Classes interactive campus

## Build
- Replace the home placeholder with a playable, mobile-friendly 3D coaching-campus experience and an always-available Classic view for parents.
- Create a lightweight low-poly campus and primitive student character, with keyboard/touch movement, tap-to-walk, building collision, camera follow, accessible controls, and section panels.
- Add the requested courses, results, faculty, fees, and validated demo enquiry content; the form confirms locally and provides a pre-filled WhatsApp link.
- Add a short start screen, mobile joystick, WhatsApp shortcut, reduced-motion handling, and footer.

## Technical approach
- Honor the requested React Three Fiber 8 / Drei 9 pairing by moving this template to React 18, then add the scene and Three.js types.
- Keep game movement and collision rules in plain TypeScript with focused tests; keep rendering and interface state in client-side React modules.
- Define the supplied Nunito and brand palette in the global design tokens, and add unique home-page metadata.
- Verify the route, game start and main enquiry flow in preview; commit the finished changes.
